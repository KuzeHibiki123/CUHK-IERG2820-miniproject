# K2 clock-rate selection — 2026-10-14

The previous fixed 10 Hz execution rate is replaced by two selectable rates.
Power-up and K4 reset select 50 MHz. Each debounced high-level K2 press toggles
50 MHz -> 1 Hz -> 50 MHz. Release K2 before pressing again; holding it does not
repeat. K2 uses the user-confirmed PIN_101. Its nCEO configuration function is
released for regular user I/O after configuration. Existing pin assignments,
including CCLK on PIN_141, are preserved.

All internal state, synchronizers and debouncers remain clocked by CLK_50.
The rate selector changes Q2's execution enable and the CCLK observation
output. This avoids clocking button filters at 1 Hz and missing short presses.
In fast mode, a debounced SW1 command can execute on the next 50 MHz edge.
In slow mode, the existing one-command queue waits for the next 1 Hz rising
edge. A pending command survives switching back to fast and executes once.
No command is generated by K2 itself. Q1 remains driven by each SW1 press.

The slow divider counts 25,000,000 input cycles per half-period at 50 MHz.
The mode selection for CCLK changes on the input falling edge; execution
remains on input rising edges. A rate change restarts the slow divider;
the transition interval is not a complete steady-state clock period.
CCLK must not be used as an internal fabric clock.
